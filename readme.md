个人利用ai辅助开发的第一个mod，就当是学习和练手用的（虽然基本上绝大多数代码都是ai生成的然后我自己进行代码校验），所以代码里是一堆注释
虽说会c#但是上班时写的大部分都是lua而且主要是干ui仔的活所以确实需要ai辅助来上手
基本上是冲着在rimworld里还原钢4的 TNO mod的超事件效果去的，但是先叠个甲，别说我是什么tno小鬼就是了
本来想在信件系统的源头进行patch的，结果发现触发信件系统的入口多的要死，最后用了个笨办法，利用信件系统的标题的原始key在游戏初始化时建立文本本地化后的dictionary来进行文本命中匹配，理论上可以支持所有语言的且本地化文本是固定内容的信件标题进行触发
以及，目前看后续如果有人想要依赖这个mod做超事件扩展来增加超事件的话，基本上只要写xml就行了，可以参考SuperEventDefs.xml和对应本地化文本xml SuperEvent_Strings.xml
mod工程已经开源到个人github仓库：https://github.com/sakuyaMZ/RimWorldMod_SuperEventFramework
